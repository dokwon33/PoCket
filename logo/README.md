# PoCket 로고 애셋

## 파일 목록

| 파일 | 용도 | viewBox |
|---|---|---|
| `pocket-symbol-color.svg` | 기본 심볼 | 88 × 88 |
| `pocket-symbol-mono.svg` | 단색 흑백 (인쇄, 자수, 각인) | 88 × 88 |
| `pocket-symbol-inverse.svg` | 어두운 배경용 | 88 × 88 |
| `pocket-lockup-horizontal-color.svg` | 가로형 조합 | 258 × 88 |
| `pocket-lockup-horizontal-mono.svg` | 가로형 조합 단색 | 258 × 88 |
| `pocket-app-icon-1024.svg` | 앱 아이콘 | 1024 × 1024 |
| `pocket-favicon-32.svg` | 파비콘, 소형 UI | 32 × 32 |
| `pocket-favicon-16.svg` | 최소 크기 | 16 × 16 |

## 제도 규칙

모듈 단위 `u` 하나에서 전부 파생됩니다. 전체 폭이 `S`일 때 `u = S / 11`.

| 요소 | 값 | 88px 기준 |
|---|---|---|
| 셀 크기 | `3u` | 24 |
| 셀 간격 | `1u` | 8 |
| 모서리 반경 | `u` | 8 |
| 외곽선 두께 | `0.375u` | 3 |
| 사방 여백 | `2u` | 16 |
| 앱 아이콘 배경 반경 | 변 길이 × 0.25 | 256 (1024 기준) |
| 앱 아이콘 내부 심볼 | 변 길이 × 0.559 | 572 (1024 기준) |

외곽선 셀은 21 × 21 크기에 두께 3의 선을 중앙 정렬해 외곽 21 + 3 = 24로 채워진 셀과 같은 크기가 됩니다.

## 크기별 대응

| 크기 | 남기는 정보 | 파일 |
|---|---|---|
| 48px 이상 | 3 × 3 그리드 전체 | `pocket-symbol-*.svg` |
| 24 ~ 32px | 외곽 프레임 + 활성 셀 | `pocket-favicon-32.svg` |
| 16px 이하 | 활성 셀만 | `pocket-favicon-16.svg` |

## 컬러

| 항목 | 값 |
|---|---|
| 활성 셀 그라데이션 | `#7F77DD` → `#378ADD`, 45도 |
| 비활성 셀 (라이트) | `#B9B4EC` |
| 비활성 셀 (단색 흑백) | `#8B8B89` |
| 비활성 셀 (반전) | `#A0A09F` |
| 워드마크 | `#3C3489` |
| 단색 흑백 활성 셀 | `#2C2C2A` |

비활성 셀에 투명도를 쓰지 않아 자수, 실크스크린, 단색 인쇄에서 그대로 재현됩니다.

### 명암비

흰색 글자를 그라데이션 위에 올리면 3.6 : 1로 WCAG AA 일반 텍스트 기준(4.5 : 1)에 못 미칩니다. 로고 자체는 WCAG 1.4.3 예외 대상이지만, 같은 그라데이션을 버튼이나 배지에 쓸 경우 `#534AB7` → `#185FA5` (6.5 : 1)로 내려야 합니다.

## 알려진 제약

- 가로형 조합의 워드마크는 `<text>` 요소이며 `Inter` → `Helvetica Neue` → `Arial` 순으로 폴백합니다. 최종 인쇄물이나 배포용으로는 글자를 패스로 변환해야 환경에 관계없이 같은 형태가 나옵니다.
- 그라데이션은 `objectBoundingBox` 기준이라 요소 크기에 따라 각도가 달라집니다. 정확한 45도가 필요하면 `gradientUnits="userSpaceOnUse"`로 바꿔야 합니다.
- 같은 페이지에 여러 SVG를 인라인으로 넣으면 `<linearGradient>` id가 충돌할 수 있어 파일마다 다른 id를 부여했습니다.

## 확장 여지

활성 셀의 위치를 옮기면 그대로 상태 표시가 됩니다.

- 로딩: 활성 셀이 순차 이동
- 빈 상태: 활성 셀 없음
- 매칭 완료: 여러 셀 점등
